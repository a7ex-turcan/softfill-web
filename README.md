# Softfill website

The public site for **Softfill**, a native iOS coloring app by nutrx labs, at
https://softfill.nutrx-labs.com. It is the app's marketing page and hosts the pages the app and App Store
Connect link to: privacy policy, terms of use and support, in English, German, Romanian and Russian.

**Status (2026-10-12):** repository set up. The Home design is approved and in `design_handoff_softfill_web/`;
the brand assets are in `src/assets/img/brand/`. The build script, templates and strings come next, in this
order: a placeholder Home so the domain resolves over HTTPS, then Privacy and Support in English (they gate
the app's first external TestFlight build), then Home, Terms and 404, then the other three languages.

## Build and preview

Plain HTML and CSS generated by one Python script, standard library only, no npm, no frameworks, no CDNs.

```bash
python3 build.py                       # src/ → docs/ (fails if a string is missing in any language)
python3 build.py --allow-missing       # while translations are drafts: fall back to English, list the gaps
python3 build.py --check               # rebuild into a temp folder and fail if docs/ is stale
python3 -m http.server 8000 -d docs    # preview at http://localhost:8000
```

Change `src/` and rebuild; never edit `docs/` by hand. Commit `src/` and the rebuilt `docs/` together.

## Where things are

- `CLAUDE.md` is the engineering guide: pages and URLs, product and privacy facts, design tokens, the build,
  hosting, constraints and the working rules. Read it first.
- `design_handoff_softfill_web/` is the approved design from Claude Design: `README.md` is the build spec for
  Home, `copy-rules.md` the copy rules, `design/*.dc.html` references to open in a browser, never code to copy.
- `src/templates/` page templates and partials, `src/strings/<lang>.json` every visible string per language,
  `src/articles/` the Privacy and Terms bodies, `src/assets/` self-hosted CSS, fonts, images, video and JS.
- `docs/` is the generated site that GitHub Pages serves.
- The app lives in a separate repo, checked out next to this one at `../softfill`. It is the source of
  truth for every product fact; start sessions with `claude --add-dir ../softfill`.

## Hosting

GitHub Pages, "Deploy from a branch", branch `main`, folder `/docs`. `docs/CNAME` holds
`softfill.nutrx-labs.com`; DNS is a CNAME at Cloudflare pointing at `a7ex-turcan.github.io`. Every change
goes through a pull request into `main`; pushing to `main` publishes the site.

## Constraints

No third-party requests of any kind: fonts, images and scripts are self-hosted, and there are no analytics,
cookies or embeds. Fast on a phone, WCAG AA, dark mode via `prefers-color-scheme`, `lang` and `hreflang` on
every page.
