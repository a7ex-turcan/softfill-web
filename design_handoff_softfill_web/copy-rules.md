# Website copy rules (merge into the web repo's CLAUDE.md)

- Never mention ads on the website in any language: no "no ads", "ad-free", "fewer ads", "no ads for kids". Rewarded ads may come later outside the kids' levels.
- Same for "no tracking" / "no analytics" / "collects no data" as selling points.
- Exception: the Privacy page states current data practices plainly as facts (e.g. "The app does not collect personal data, show ads or use analytics"), with a "last updated" date. Body text only — never a badge, chip or highlight.
- Sell what stays true: grown-up check every time, the Little level (no prices, nothing to tap away to), no accounts (device + own iCloud), calm by design (no countdowns, no scores).
